- **共同节拍**：压入/弹出、入队/出队、指针回绕、空/满边界。

## 递归（3 页）

**共享 playbook**

- **心智模型**：调用栈 = 玻璃塔/套娃；N 皇后 = 棋盘 + 激光网。
- **舞台/镜头**：每层栈帧一块半透明板，写参数/返回值；侧面看塔，回溯跟随返回值下落。
- **状态/交互**：栈深、当前 n、返回值、棋盘攻击线；选 n、单步进入/跳过、放置/撤销。
- **共同节拍**：压帧、基线、返回值下降、弹帧；皇后落下、攻击线、冲突回溯。

- **心智模型**：一棵活的树/图书馆：BST 普通树、AVL 舞者、红黑红绿灯、B 树书架、Trie 单词树、哈希桶网格。
