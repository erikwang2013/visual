# 3D 演示分镜表 · DP、贪心与几何变换

> 本文件是规划稿，不包含实现代码。表格中的“分镜节拍”来自该页算法说明的子步骤，并补充了建立/复盘。

**读表方式**：先看该类的“共享 playbook”，再逐行看页面的舞台、节拍、状态和名场面；“原型”代码见 README。

## 动态规划（7 页）

**共享 playbook**

- **心智模型**：3D 表格/地形：每格 = 一个决策，最优路径 = 山脊/路线。

- **状态/交互**：dp 表、递推、当前格、候选、路径；自定义输入、悬停格子、单步、显示路径。
- **共同节拍**：填格、候选、选择、回溯、表格变地形。

## DP 与贪心补全（10 页）

**共享 playbook**

- **心智模型**：决策地形/资源板：DP 合并块，贪心连续认领。

- **状态/交互**：已选集合、收益/覆盖、DP 表、路线；加区间/物品、选贪心顺序、单步。
