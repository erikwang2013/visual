### 最长公共子序列

**目标/逻辑**：最长公共子序列：二维 DP 表比较两串，回溯得到最长公共子序列。
**核心不变量**：dp[i][j] = 前缀 i/j 的 LCS 长度
**舞台**：LCS 表格 + 双字符串轴：匹配斜箭头，不匹配上/左箭头
**镜头**：斜视表格建立 → 当前格特写 → 回溯蛇形 → 拉远看 LCS
**状态面板**：dp 表、当前格、匹配字符、LCS 路径、长度
**交互**：输入两串；悬停格子看递推；单步；高亮路径；预测下一格

| 节拍 | 画面 / 动作 | 镜头 | 标注（为什么） | 状态面板 |
|---|---|---|---|---|
| 0 Hook | 两串字符与空表格 | 斜视 | 最长公共子序列有多长？ | dp 空 |
| 1 初始化 | 第 0 行/列置 0 | 俯视 | 空串 LCS=0 | dp 边界 |
| 2 匹配 | 字符相等，取左上+1 | 当前格 | 匹配 → 对角线 | dp 值 |
| 3 不匹配 | 取 max(上,左) | 当前格 | 不匹配 → 上/左最大 | dp 值 |
| 4 填表 | 逐行填满 | 全景 | 子问题最优 | dp 表 |
| 5 回溯 | 从右下角回走 | 沿路径 | 匹配字符逆序 | LCS 路径 |
| 6 结算 | LCS 高亮 | 拉远 | 长度/序列 | 结果 |
| 7 复盘 | 与暴力分屏 | 分屏 | DP 消除重复子问题 | O(mn) |

**名场面**：LCS 蛇形路径穿过表格，匹配字符亮起
**验收**：用户能说出匹配和不匹配分别从哪来

**镜头**：斜视表格 → 当前格特写 → 回溯选/不选 → 地形拉远
**状态面板**：dp 表、当前物品/容量、候选值、选择、最优价值
**交互**：改重量/价值/容量；悬停格子；单步；显示回溯；预测选/不选

### 最长递增子序列

**目标/逻辑**：最长递增子序列：逐位置比较前序位置，dp[i] = max(dp[j] + 1)，并回溯出最长序列。
**核心不变量**：dp[i] = 以 a[i] 结尾的 LIS 长度
**舞台**：递增山脊：数组柱阵上找最长上升脊线
**镜头**：环绕柱阵 → 跟随当前元素 → 前驱链特写 → 山脊拉远
**状态面板**：dp 长度、前驱、当前元素、LIS 路径
**交互**：输入数组；单步；高亮 LIS；对比 O(n log n)；预测下一个可接元素

| 节拍 | 画面 / 动作 | 镜头 | 标注（为什么） | 状态面板 |
|---|---|---|---|---|
| 0 Hook | 柱阵起伏，待找山脊 | 环绕 | 最长上升子序列在哪？ | dp 空 |
| 1 初始化 | 每个元素长度 1 | 推近 | 自己算一个 | dp=1 |
| 2 比较前序 | 找更小元素 | 跟随 | 能接上就 +1 | dp |
| 3 更新 | dp[i]=max(dp[j]+1) | 当前柱 | 取最长前驱 | 前驱 |
| 4 不变量 | dp[i] 以 i 结尾 | 侧视 | 状态定义决定转移 | dp |
| 5 回溯 | 从最大 dp 回走 | 沿路径 | 前驱链 = LIS | LIS 路径 |
| 6 结算 | 山脊线浮起 | 拉远 | 长度/序列 | 结果 |
| 7 复盘 | 与 O(n log n) 分屏 | 分屏 | DP 与二分的取舍 | O(n²) |

**名场面**：最长递增子序列像山脊线，从柱阵中浮起
**验收**：用户能说出状态定义为什么必须以 i 结尾

### AES

**目标/逻辑**：AES：字节代换（S 盒）→ 行移位 → 列混合 → 加轮密钥，多轮迭代的对称加密。
**核心不变量**：每轮 = SubBytes + ShiftRows + MixColumns + AddRoundKey；最后一轮无 MixColumns
**舞台**：4×4 状态方阵 + 轮密钥晶体
**镜头**：状态方阵特写 → 四层变换 → 9 轮蒙太奇 → 密文/扩散拉远
**状态面板**：状态矩阵、轮密钥、轮次、扩散率、密文
**交互**：输入明文/密钥；选轮数；单步；扩散热图；对比 AES-128/256；预测扩散范围

| 节拍 | 画面 / 动作 | 镜头 | 标注（为什么） | 状态面板 |
|---|---|---|---|---|
| 0 Hook | 16 个明文字节组成 4×4 方阵 | 推近方阵 | 改 1 字节，密文会怎样？ | 明文 |
| 1 AddRoundKey | 密钥晶体分出 16 字节注入 | 跟随密钥流 | 先混合轮密钥 | 轮密钥 |
| 2 SubBytes | 字节钻进 S 盒，变色出来 | 方阵特写 | 非线性替换，抗差分 | 轮次 1 |
| 3 ShiftRows | 四行像抽屉一样错位滑动 | 侧视四行 | 行移位：换列 | 轮次 1 |
| 4 MixColumns | 四列像调色一样混合 | 俯视列 | 列混合：1 字节影响整列 | 扩散率 |
| 5 九轮蒙太奇 | 四层循环，扩散热图铺满 | 环绕 | 每轮扩散 4 倍 | 轮次 9 |
| 6 最终轮 | 无 MixColumns | 特写 | 最后一轮结构不同 | 轮次 10 |
| 7 结算 | 密文定格，与 FIPS 向量比对 | 拉远 | 1 字节变化扩散到整块 | 密文 |
| 8 复盘 | 与 DES 分屏 | 分屏 | AES = 代换+置换+混合 | O(轮数) |

**名场面**：AES 墨滴扩散：1 字节变化染遍整块
**验收**：用户能说出四层各自负责什么

### RSA

**目标/逻辑**：RSA：选两个大素数求模数 n 与 φ(n)，公钥加密 C=M^e mod n，私钥解密 M=C^d mod n。
**核心不变量**：M^(ed) ≡ M mod n（欧拉定理）
**舞台**：锁/钥匙：p/q、模幂、公私钥
**镜头**：大素数特写 → 密钥生成 → 模幂齿轮 → 锁/钥匙拉远
**状态面板**：p/q、n、φ、e/d、模幂、密文
**交互**：输入素数/消息；加密/解密；单步；显示密钥生成；对比对称加密

| 节拍 | 画面 / 动作 | 镜头 | 标注（为什么） | 状态面板 |
|---|---|---|---|---|
| 0 Hook | 锁/钥匙与大素数 | 环绕 | 为什么公钥能公开？ | p/q |
| 1 选素数 | p/q 生成 n/φ | 特写 | n=pq，φ=(p-1)(q-1) | n/φ |
| 2 公钥 | 选 e，公开 | 锁特写 | e 与 φ 互素 | e/n |
| 3 私钥 | d=e⁻¹ mod φ | 钥匙特写 | d 是 e 的模逆 | d |
| 4 加密 | C=M^e mod n | 模幂齿轮 | 公钥锁上 | 密文 |
| 5 解密 | M=C^d mod n | 钥匙开锁 | 私钥打开 | 明文 |
| 6 不变量 | 欧拉定理验证 | 侧视 | M^(ed)=M mod n | 验证 |
| 7 复盘 | 安全性定格 | 静止 | 大整数分解难 | 复杂度 |

**名场面**：公钥锁上、私钥打开，模幂像齿轮
**验收**：用户能说出为什么公钥可以公开
